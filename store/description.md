## Short description

A new 5-letter word every day for all of Root, unlimited freeplay, and one leaderboard across every server.

## Full description

Wordy is a daily word game for your server, where everyone on Root gets the same word.

**The daily word**
- Guess the hidden 5-letter word in 6 tries
- One new word a day at midnight UTC, the same in every server
- One ranked try each, and the timer starts when you press start
- Copy a spoiler-free result grid to share in chat

**Freeplay**
- Play as many words as you like
- Pick 4, 5, 6 or 7 letters
- Hard mode: any letter you find has to be used again

**Leaderboards**
- Today: fewest guesses wins, and the fastest time breaks ties
- Streaks, all-time average and freeplay wins this week
- Every board works for all of Root or just your server
- A servers board: each server's best 10 players today, so a small active server can beat a big one

**Made for playing**
- Type on your keyboard or tap the on-screen keys
- Pink for the right spot and lavender for the wrong spot, with a dot and a triangle on the tiles for colorblind players
- Light and dark themes that follow Root
